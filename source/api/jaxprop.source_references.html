jaxprop.source_references module#

Immutable source-EOS reference data, independent of numerical evaluators.

Only scalar Python metadata is retained. Reference FluidState arrays are materialized on explicit access, so these records are safe static JAX metadata. Every initialization probes a fresh source anchor: CoolProp reference settings are process-global and a cache keyed only by fluid name would become stale.

jaxprop.source_references.initialize_source_references(name, backend='HEOS', *, state=None)[source]#

Initialize independently available source critical/lower-endpoint records.

An evaluator may supply its freshly constructed source state so ordinary evaluation and reference records capture the same convention, even if the process-global convention changes during construction. This is setup-only: callers must not pass a state serving an in-flight numerical evaluation.
