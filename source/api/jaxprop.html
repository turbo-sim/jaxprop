jaxprop package#

Thermodynamic models with consumer-controlled JAX execution settings.

When JaxProp imports JAX first, double precision remains the default for scientific calculations. An explicit JAX_ENABLE_X64 environment setting, or an application that imports/configures JAX before JaxProp, takes priority. Choose devices through JAX’s own configuration before constructing models; importing this package does not select a platform or install an exception hook.
