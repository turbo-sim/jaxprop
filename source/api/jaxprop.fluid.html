jaxprop.fluid module#

The common fluid constructor and public runtime fluid type.

class jaxprop.fluid.Fluid(name, method='coolprop', backend=None, identifier=None, *, table_options=None, model_options=None, **options)[source]#

Bases: object

Construct the selected evaluator without wrapping its numerical calls.

method selects the numerical implementation and physical model. backend selects its CoolProp source, with None resolving to HEOS for single-source methods. Table and calibration settings use their respective option mappings. A binary model takes configured components and fixed mass fractions through model_options.

The result is the actual evaluator, such as FluidCoolProp or FluidPerfectGas. Evaluator classes are registered virtual subclasses, so isinstance(result, Fluid) works without adding a wrapper or changing their JAX PyTrees. Virtual rather than physical inheritance also prevents Python from initializing the already constructed result a second time.
