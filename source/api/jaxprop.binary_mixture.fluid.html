jaxprop.binary_mixture.fluid module#

A fixed-composition binary model using configured component evaluators.

The parcels share pressure and temperature, without mass exchange or molecular mixing entropy. This differs from a mixture equation of state. Numerical providers are selected on the components; no source is initialized by a call.

class jaxprop.binary_mixture.fluid.FluidBinaryMixture(name, components, mass_fractions, identifier=None, *, inverse_max_steps=64, inverse_tolerance=1e-10)[source]#

Bases: SourceReferencesMixin, Module

Fixed mass fractions of two component fluids in mechanical/thermal equilibrium.

Parameters:
namestr

User label; component names and backends stay on the component objects.

componentspair of configured fluid objects

Components must provide PT core states and thermal response properties. Native PG/bicubic components remain dynamic JAX model data. Host/hybrid configurations are fixed snapshots; reconstruct to change their models.

mass_fractionspair of nonnegative real scalars

Sum to one, without normalization. Both pure-component limits are valid. Composition is fixed, never an extra positional state input.

identifierstr or None

Stream label preserved on complete returned FluidState objects.

inverse_max_steps, inverse_toleranceint, float

Setup-only iteration budget and scaled residual tolerance for HP/PS.

The main sound speed assumes pressure and temperature relaxation. The named
``speed_of_sound_p`` field retains the distinct frozen-thermal Wood speed.
Component mass fractions are not vapor qualities; saturation is unsupported.
