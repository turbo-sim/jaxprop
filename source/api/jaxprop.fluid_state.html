jaxprop.fluid_state module#

Immutable, JAX-compatible fluid values with explicit property availability.

class jaxprop.fluid_state.FluidState(fluid_name=None, identifier=None, *, provider=None, providers=None, model=None, reference_id=None, available_properties=None, error_policy='raise', status=None, clipped=None, property_validity=None, **properties)[source]#

Bases: Module

A numeric pytree whose public properties enforce their availability.

Raw leaves are private so Equinox/JAX transformations never invoke guarded public lookups. Metadata contains only immutable, non-array values.
