class jaxprop.bicubic.bicubic_interpolation.FluidBicubic(fluid_name: str = None, backend: str = 'HEOS', h_min: float = None, h_max: float = None, p_min: float = None, p_max: float = None, N_h: int = None, N_p: int = None, N_p_sat: int = 60, mixture_ratio: float = None, metastable_phase: str = None, coarse_step: int = 10, gradient_method: str = 'central', identifier: str = None, table_name: str = None, table_dir: str = 'fluid_tables', *, name: str = None, inverse_max_steps: int = 64, inverse_tolerance: float = 1e-10, metastable_domain: str = 'physical')[source]#

Bases: SourceReferencesMixin, Module

Fluid model using bicubic property interpolation on an enthalpy-pressure grid.

Workflow:

  • On construction, attempts to load a precomputed table from disk.

  • If not found, generates the table with finite-difference derivatives, saves it to disk, and stores it in memory.

  • On get_state, performs bicubic interpolation at the requested state.

Generation uses the selected finite-difference scheme. Cache reuse requires an exact generation manifest, verified source identity and valid arrays.

Parameters:

Fluid identifier for CoolProp.

CoolProp backend string.

Min/max pressure [Pa].

Number of grid points in h and p.

coarse_stepint

Number of points to skip when determining the initial guess during 2D inverse interpolations

inverse_max_stepsint, optional

Nonnegative iteration limit for property-pair inverses (default: 64).

inverse_tolerancefloat, optional

Positive tolerance for the nonlinear solver and its independent scaled residual check (default: 1e-10). These inverse controls do not change table generation or the persisted cache identity.

metastable_domain{‘physical’, ‘formal’}, optional

Physical metastable tables require positive constant-volume heat capacity and isothermal bulk modulus at source samples. Formal mode explicitly permits calorically unstable homogeneous EOS states for research. Cells that may cross a heat-capacity pole do not expose the affected response properties. Both modes retain mechanical guards. Stability is prepared during construction, with no added EOS queries in interpolation. The default is ‘physical’.

table_namestr, optional

File stem. The default includes a digest of the complete generation identity so different configurations can coexist in one cache directory.

table_dirstr, optional

Directory for saving/loading table pickle (default: “fluid_tables”).

identifierstr, optional

Tag stored in the returned FluidState objects.

Evaluate a bounded table state with explicit numerical failure policy.

The input-pair selector is static for JAX compilation; numerical inputs and table coefficients remain dynamic. Each pair has its own cached specialization, so the same fluid object supports different advertised pairs throughout a simulation without specializing on numerical values.

Eager calls default to indexed raising. Within JAX transformations, explicitly select errors='mask' or errors='clip'.
