## Rebuild and install

With `build`, `poetry-core` and `twine` installed in a dedicated packaging
environment, run from the JaxProp checkout:

```powershell
python -m build --no-isolation --outdir dist
python -m twine check --strict dist/jaxprop-0.6.0.tar.gz dist/jaxprop-0.6.0-py3-none-any.whl
```

In each downstream environment, install the prepared wheel explicitly:

```powershell
python -m pip install C:/Users/roagr/git_projects/jaxprop/dist/jaxprop-0.6.0-py3-none-any.whl
python -I -c "import jaxprop; print(jaxprop.__version__, jaxprop.__file__)"
python -m pip check
```

Record the actual artifact SHA256 with each downstream run. Rebuilding may
change archive hashes even when source is unchanged; use the saved artifact for
the first matched integration run. If integration requires a library repair,
repeat affected tests, rebuild and update the manifest before publishing.
